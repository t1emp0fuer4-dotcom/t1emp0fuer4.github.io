# ⚡ Fluxo — Física y electrónica interactiva

Una web educativa en español que transforma conceptos abstractos de física en
**laboratorios interactivos en tiempo real**.

## 🎯 ¿Qué es?

Fluxo convierte fórmulas en experiencias: arrastra cargas eléctricas, juega con
las ecuaciones de Maxwell, explora el espectro electromagnético y calcula circuitos
en vivo. **La física no se memoriza: se toca.**

## ✨ Características

- 🌊 **Hero animado** — Canvas con partículas y ondas reactivas al cursor
- 📐 **4 ecuaciones de Maxwell** — visualizadas con animaciones en Canvas
- ⚡ **Laboratorio de campos** — editor interactivo de cargas +/- con vectores en tiempo real
- 🌈 **Explorador del espectro** — de 10 kHz a 100 EHz con onda de color real
- 🔌 **Ley de Ohm interactiva** — electrones circulando, LED con brillo dinámico
- 🎨 **Código de colores** — calculadora de resistencias con 4 bandas
- 🧠 **Quiz + curiosidades** — con carrusel de datos científicos
